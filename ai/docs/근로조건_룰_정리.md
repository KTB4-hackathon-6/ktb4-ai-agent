# 근로조건 룰 엔진 정리

`ai/src/ai_agent/services/rules.py`의 `check_contract()`가 판정하는 규칙 전체 목록.
LLM은 계약서에 적힌 값을 읽기만 하고, 아래 판정은 전부 코드(if-else)로 결정한다.

## 판정 규칙

| rule_id | 법령 | 조항 | 판정 조건 | 심각도 |
|---|---|---|---|---|
| `required_disclosure_missing` | 근로기준법 | 제17조 | 임금·근로시간·휴일·임금지급일 중 미명시 항목이 있으면 (항목별로 각각 발생) | WARNING |
| `below_minimum_wage` | 최저임금법 | 제6조 | 시급 < 10,320원 (2026년 최저임금, 매년 갱신 필요) | WARNING |
| `weekly_hours_exceeded` | 근로기준법 | 제53조 | 주당 근로시간 > 52시간 (기본 40 + 연장 12) | WARNING |
| `rest_time_insufficient` | 근로기준법 | 제54조 | 1일 8시간↑ 근무인데 휴게 60분 미만 (4시간↑는 30분 미만) | WARNING |
| `weekly_holiday_missing` | 근로기준법 | 제55조 | 주 유급휴일 < 1회 | WARNING |
| `contract_period_exceeded` | 외국인근로자의 고용 등에 관한 법률 | 제18조 | 근로계약기간 > 36개월(3년, 취업활동기간 상한) | WARNING |
| `in_person_payment_risk` | 근로기준법 | 제43조 | 임금 지급방법이 통장입금이 아닌 현금 직접지급 | REVIEW |
| `accommodation_deduction_high` | 외국인근로자의 고용 등에 관한 법률 | 숙식비 공제지침 | 숙박비 공제액 ≥ 월급의 15% (⚠️ 공식 지침 원문 미확인, 보수적 추정치) | REVIEW |

**업종 예외**: `industry`가 농업·축산·수산업(`agriculture_livestock_fishery`)이면 근로기준법 제63조에 따라
`weekly_hours_exceeded`, `rest_time_insufficient`, `weekly_holiday_missing` 3개는 아예 체크하지 않는다.

**심각도 구분**: WARNING = 법정 기준 대비 명확한 위반. REVIEW = 위법 단정은 아니지만 사람이 확인해야 하는 리스크 신호.

## 추출값을 못 믿을 때 (unverified_fields)

`services/extraction.py`가 OCR 원문에서 근거를 확인 못했거나(grounding 실패) 값 자체가 앞뒤가 안 맞으면
해당 필드명을 `unverified_fields`에 담아 반환한다. `suppress_unverified()`가 그 필드에 의존하는 위반만
결과에서 제외한다 — 전체 요청을 실패시키지 않고, 확신 없는 필드의 판정만 조용히 뺀다.

| unverified 필드 | 제외되는 rule_id |
|---|---|
| `monthly_wage` | `below_minimum_wage` |
| `rest_minutes_per_workday` | `rest_time_insufficient` |
| `weekly_paid_holidays` | `weekly_holiday_missing` |
| `contract_period_months` | `contract_period_exceeded` |
| `accommodation_deduction_krw` | `accommodation_deduction_high` |
| `weekly_working_hours` | `weekly_hours_exceeded` |
| `daily_working_hours` | `weekly_hours_exceeded`, `rest_time_insufficient` |

## 알려진 제한사항

- `accommodation_deduction_high`의 15% 기준선은 고용노동부 숙식비 공제지침 원문(HWP 첨부)을 확인 못해
  보수적으로 잡은 추정치. 공식 지침 확인 후 검증 필요.
- `weekly_working_hours`는 계약서에 literal하게 안 적혀있어(시작~종료 시각에서 계산) 반복 호출 시
  값이 다소 흔들릴 수 있음. plausibility 체크(하루 근로시간~하루×7일 범위)로 명백히 틀린 값만 걸러냄.
- 표준근로계약서 2개 서식(제조업용 별지 제6호서식, 농업·축산·어업용 별지 제6호의2서식)만 검증함.
