# 외국인근로자 근로조건 관련 법령 정리

## 근로기준법

| 조항 | 내용 |
|---|---|
| 제17조 | 근로계약 체결 시 임금·소정근로시간·휴일·연차유급휴가 등 서면 명시 의무 |
| 제43조 | 임금 직접·전액·통화·정기 지급 원칙 |
| 제50조 | 1주 40시간, 1일 8시간 초과 금지 |
| 제53조 | 연장근로는 합의 시 주 12시간 한도 |
| 제54조 | 4시간당 30분, 8시간당 1시간 이상 휴게 |
| 제55조 | 주 1회 이상 유급휴일 |
| 제56조 | 연장·야간·휴일근로 시 통상임금 50% 가산 |
| 제60조 | 1년 이상·80% 출근 시 연차 15일 |
| 제63조 | 농림·축산·양잠·수산업은 근로시간·휴게·휴일 규정 적용 제외 |

## 최저임금법

| 조항 | 내용 |
|---|---|
| 제5조 | 최저임금액의 결정 기준, 도급제 등 |
| 제6조 | 최저임금 이상 지급 의무 |
| 제10조 | 최저임금의 고시 (매년 8월 5일까지 고용노동부장관이 다음 연도 최저임금 고시) |

## 외국인근로자의 고용 등에 관한 법률

| 조항 | 내용 |
|---|---|
| 제9조 | 근로계약 체결 시 표준근로계약서 사용 의무 |
| 제13조 | 출국만기보험 — 사용자 의무가입 (퇴직금 대체 성격) |
| 제15조 | 보증보험 — 사용자 의무가입 (임금체불 대비) |
| 제18조 | 취업활동 기간 3년 |
| 제18조의2 | 취업활동 기간 연장 — 1회에 한해 최대 1년 10개월 추가 (총 4년 10개월 상한, 5년 이상 연속체류 시 발생하는 다른 체류자격 요건 충족을 막기 위함) |
| 제22조 | 외국인이라는 이유로 부당한 차별적 처우 금지 |
| 제23조 | 귀국비용보험 — 외국인근로자 의무가입 (귀국 시 항공권 등 비용 대비) |
| 제27조 | 상해보험 — 외국인근로자 의무가입 (업무상 재해 외의 상해·질병 대비) |

## 외국인근로자의 고용 등에 관한 법률 시행규칙

| 항목 | 내용 |
|---|---|
| 별지 제6호서식 | 표준근로계약서 (제조업 등 일반) |
| 별지 제6호의2서식 | 표준근로계약서 (농업·축산업·어업 분야) |

## 고용노동부 숙식비 공제 관련 지침

숙식정보 제공 및 비용징수 관련 업무지침 — 숙박비·식비 공제 한도 규정

## 4대보험 관련 법령

| 법령 | 내용 |
|---|---|
| 국민건강보험법 | 외국인근로자 건강보험 적용 |
| 국민연금법 | 외국인근로자 국민연금 적용 (상호주의) |
| 고용보험법 | 고용안정·직업능력개발사업은 사업장 규모별 의무가입, 실업급여는 외국인근로자 희망 시에만 가입하는 임의가입 |
| 산업재해보상보험법 | 외국인근로자 산재보험 적용 |
| 근로자퇴직급여 보장법 | 퇴직금 관련 |
